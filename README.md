# PARKERZ PROJECT 

This is a parking management web application developed using HTML, CSS, and JavaScript.

This project was developed as a  part of team project.
I contributed to frontend development and implement.

Developed a smart parking management application that helps users find and reserve available parking slots. Implemented intelligent parking-slot recommendation to reduce parking search time and improve parking efficiency. Designed for real-world applications such as shopping malls and IT companies, with centralized parking and booking management.
